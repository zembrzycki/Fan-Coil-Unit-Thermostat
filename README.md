# Z-Rated Thermostat for the Sonoff NSPanel US

A standalone thermostat for a 2-pipe fan coil unit (FCU), running ESPHome on a Sonoff NSPanel US with a custom Nextion screen.

![Screens](docs/firmware_screens.png)

## Features

- **Runs on its own.** The room temperature comes from the panel's built-in sensor. Home Assistant only supplies the loop-water and outdoor temperatures, and the thermostat keeps working if HA goes offline.
- **Two relays:**
  - Relay 1 switches the fan and zone valve.
  - Relay 2 switches the fan to high speed.
- **Seasonal changeover.** When the loop water moves into a new band (cooling, heating, or inactive), the mode switches once. You can always change the mode by hand, and that choice stands until the next real change.
- **Auto fan speed.** During a call, the fan steps up to High when the room is more than a set number of degrees from the setpoint. After every call, the speed returns to Low.
- **Settings on the panel.** Hold both hardware buttons for 2 seconds to open Settings: setpoints, fan options, screen, sensors, Wi-Fi and About. Every setting is also exposed in Home Assistant.
- **Clean screen.** A Z-Rated boot screen and a dark home screen. The Montserrat and icon fonts are generated by this repo.

## Files

| File | What it is |
|---|---|
| `nsp3.yaml` | ESPHome firmware |
| `thermostat_us.HMI` | Nextion Editor project; compile it to `thermostat_us.tft` |
| `secrets.yaml.example` | The secrets `nsp3.yaml` expects |
| `tools/tft_serve.py` | Small web server for uploading the screen file (see below) |
| `hmi_src/` | Generator for `thermostat_us.HMI`: layout, fonts, backgrounds |
| `base/` | Blank project saved by Nextion Editor; the build starts from it |
| `tests/` | Simulation and file checks |

## Install

1. **Compile the screen.** Open `thermostat_us.HMI` in Nextion Editor, click **Compile**, then use **File → TFT file output** to save `thermostat_us.tft`.
2. **Serve it.** Put `thermostat_us.tft` and `tools/tft_serve.py` in the same folder, then run:
   ```bash
   python3 tft_serve.py
   ```
   The server prints the URL to use as `tft_url` in `nsp3.yaml`.
3. **Flash the firmware.** Add your secrets, set `tft_url`, and install `nsp3.yaml` from the ESPHome dashboard.
4. **Load the screen.** In Home Assistant, open the device page and press **Update Display Firmware**. It takes about 6 minutes.

> **Why not host the file in Home Assistant?** ESPHome's Nextion uploader needs a plain-HTTP server that answers `HEAD` and `Range` requests. Recent Home Assistant releases return 404 to `HEAD` on `/local`, and the uploader can't use HTTPS. `tft_serve.py` handles both requests. Any nginx/Caddy server also works.

## Home Assistant entities

| Entity | Purpose |
|---|---|
| `climate.<device>_thermostat` | Mode (off/cool/heat), cool and heat setpoints, fan mode (low/high) |
| `switch.<device>_fan` | Relay 1 (fan + valve) |
| `switch.<device>_fan_speed` | Relay 2 (high speed); stays in sync with the climate fan mode |
| `switch.<device>_auto_changeover` | Seasonal changeover on/off |
| `switch.<device>_auto_fan_speed` | Automatic step-up to High |
| `switch.<device>_resume_after_plant_off` | Resume heating/cooling after the plant turned the unit off |
| `number.<device>_*` | Water thresholds, changeover delay, auto fan speed delta, temperature offset, screen brightness and timers |
| `sensor.<device>_active_setpoint` | The setpoint for the current mode |
| `sensor.<device>_plant_mode` | Cooling / Heating / Inactive |

## Configuration

Everything you're likely to change is in the `substitutions:` block at the top of `nsp3.yaml`:
- the HA entity ids for loop-water and outdoor temperature;
- the first-boot defaults;
- the setpoint limits;
- the hardware pins.

Runtime settings are stored on the device and can be changed from HA or from the panel.

## Hardware

Sonoff NSPanel US (ESP32, Nextion NX4832F035, 180° vertical):

| Pin | Function |
|---|---|
| GPIO22 | Relay 1 |
| GPIO19 | Relay 2 |
| GPIO38 | NTC temperature sensor |
| GPIO16 / GPIO17 | Display UART |
| GPIO4 | Display power |
| GPIO14 / GPIO27 | Hardware buttons |

> ⚠️ This device switches mains-powered equipment. Install it to code, or have it installed.
